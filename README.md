# EventSphere

## Event Planning & Resource Management System

EventSphere is a web-based event management system designed to simplify event planning, participant registration, vendor management, resource allocation, budgeting and event operations.

---

# Project Progression

## Milestone 1

Build the Foundation

Features:

- Event Management
- Venue Management
- Resource Management
- Event Planning

---

## Milestone 2

Manage People & Vendors

Features:

- Participant Registration
- Digital Tickets
- QR Code
- Attendance
- Vendor Management

---

## Milestone 3

Connect & Automate the System

Features:

- REST APIs
- Budget Management
- Expense Tracking
- Sponsorship Management
- Notifications
- Reminders
- Approval Workflow
- Organizer Operational Dashboard
